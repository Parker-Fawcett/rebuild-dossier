Reverse-engineer a trustworthy rebuild spec from an existing app.

An MCP server that produces a locked CLAUDE.md, .claude/ config, and a mutation-tested test suite out of your codebase. Any coding agent can rebuild against that spec instead of guessing.

npm Smithery GitHub arXiv:2608.23616

How it works

ingest_repo

Static analysis — routes, package.json, build config, tests, structural smell detectors. No LLM call.

crawl_site

Headless Playwright crawl of reachable routes with progress notifications.

flag_known_bug

Free text ambiguity flag. Stored verbatim. Always overrides auto-resolve.

get_case_queue

The ambiguity queue. Surfaces open questions via MCP elicitation.

resolve_case

Answer a queued question with a decision.

generate_spec

Only once the queue is empty. Writes CLAUDE.md, spec/, tests/, and kickoff-prompt.txt to a clean sibling directory.

Install

npx rebuild-dossier@latest --help
npm install -g rebuild-dossier
brew install rebuild-dossier

Requires Node 20.12+. Add as an MCP server in Claude Code, Cursor, Windsurf, or any MCP-compatible client.
