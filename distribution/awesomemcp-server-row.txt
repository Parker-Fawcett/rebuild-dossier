PR BODY
Adds the rebuild-dossier MCP server to Developer Tools.

An MCP server that reverse-engineers a rebuild spec out of an existing app: a
locked CLAUDE.md, .claude config, and mutation-tested test suite, so a coding
agent can rebuild the app cleanly against it instead of guessing. It does not
rebuild the app; it produces the spec, contracts, and tests a separate agent
consumes.

Six tools: ingest_repo, crawl_site, generate_spec, flag_known_bug,
get_case_queue, resolve_case.

Install: npx rebuild-dossier@latest
