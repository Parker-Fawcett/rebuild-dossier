Short description (one line, click-through focused):
MCP server that reverse-engineers a locked rebuild spec (CLAUDE.md, .claude
config, mutation-tested tests) from an existing app, so a coding agent can
rebuild it without guessing.

Longer description / features:
Six tools: ingest_repo, crawl_site, generate_spec, flag_known_bug,
get_case_queue, resolve_case. It does not rebuild the app; it produces the
spec, contracts, and tests a downstream agent consumes.

Transport: stdio (default, npx) and HTTP/SSE with bearer auth.
Install:  npx rebuild-dossier@latest
Full setup + security config in the README.
